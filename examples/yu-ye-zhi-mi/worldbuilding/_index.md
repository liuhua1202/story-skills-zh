# Worldbuilding

## World Overview

故事发生在 **2057 年的砚城**——一座虚构的中国东南沿海小城，地处丘陵与海湾之间，老城依山，新城向海。城市规模约四十二万人口，靠海吃饭，靠填海扩张，靠"宜居样板"这个标签在 2008-2057 这五十年里一次次过关。

这是一座**已经选择遗忘**的城市。但遗忘不是一天完成的——它是几代工程师、几个签字、几次验收报告、几块牌匾、几场暴雨共同压出来的。
