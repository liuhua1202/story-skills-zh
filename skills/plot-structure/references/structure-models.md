# 故事结构模型参考

常见的结构模型与节拍清单。**节拍清单是起点，不是教条**——按需要调整、混搭、删减。结构服务于故事，不是反过来。

> 落点原则：选定一个模型后，把节拍表回填到 `plot/_index.md` 的"故事结构"小节，并在每条节拍里绑定具体章节 id。这样 `story next .` 才能根据节拍进度推算下一步。

---

## 一、三幕结构（Three-Act）

最常用的西方主流结构。简单、灵活、读者预期清晰。适合大多数商业小说、长篇连载、电影剧本。

| 节拍 | 幕 | 位置 | 说明 |
| --- | --- | --- | --- |
| 开场（Opening） | 第一幕 | ~1% | 建立日常世界与主角 |
| 激励事件（Inciting Incident） | 第一幕 | ~10% | 打破现状的事件 |
| 第一情节点（First Plot Point） | 第一幕 / 第二幕分界 | ~25% | 主角决定上路，进入新世界 |
| 上升情节（Rising Action） | 第二幕 | 25–50% | 主角遇到升级的阻碍 |
| 中点（Midpoint） | 第二幕 | ~50% | 重大反转、揭示或假胜利 / 假失败 |
| 危机（Crisis） | 第二幕 | 50–75% | 赌注升高，处境恶化 |
| 第二情节点（Second Plot Point） | 第二幕 / 第三幕分界 | ~75% | 看似一切尽失的最低点 |
| 高潮（Climax） | 第三幕 | ~90% | 最终对决 / 最终抉择 |
| 收束（Resolution） | 第三幕 | ~99% | 新的常态，余波收尾 |

**适合**：奇幻、悬疑、爱情、成长、动作冒险等绝大多数商业类型。

---

## 二、英雄之旅（Hero's Journey · Campbell / Vogler）

神话原型结构，主角通过一系列试炼完成蜕变。常用于奇幻、史诗、冒险、成长小说。

| 节拍 | 阶段 | 说明 |
| --- | --- | --- |
| 平凡世界（Ordinary World） | 启程 | 主角原本的生活 |
| 冒险召唤（Call to Adventure） | 启程 | 挑战或机遇出现 |
| 拒绝召唤（Refusal of the Call） | 启程 | 主角犹豫、抗拒或拖延 |
| 遇见导师（Meeting the Mentor） | 启程 | 导师出现，传授智慧或工具 |
| 跨越门槛（Crossing the Threshold） | 启程 | 主角进入未知的世界 |
| 试炼、盟友、敌人（Tests, Allies, Enemies） | 入门 | 主角学习新规则，结识朋友与敌人 |
| 接近最深的洞穴（Approach to the Inmost Cave） | 入门 | 为核心试炼做准备 |
| 严酷考验（The Ordeal） | 入门 | 重大危机，死亡与重生时刻 |
| 奖赏（Reward） | 入门 | 主角获得所求之物 |
| 归途（The Road Back） | 归返 | 主角返程，被后果追逐 |
| 复活（Resurrection） | 归返 | 最终考验，蜕变完成 |
| 携灵药归来（Return with the Elixir） | 归返 | 主角归来改变，带回礼物 |

**适合**：奇幻、神话、成长小说、超级英雄；主角弧明确、内在与外在变化并行的故事。

---

## 三、救猫咪（Save the Cat · Snyder）

编剧圈广泛使用的 15 节拍清单。节拍密集，适合节奏紧凑的商业小说、长篇连载、电影感强的小说。

| 节拍 | 位置 | 说明 |
| --- | --- | --- |
| 开场画面（Opening Image） | ~1% | 用一个画面/意象/场景给出主题与起点 |
| 主题陈述（Theme Stated） | ~5% | 用一句对话或旁白把主题悄悄说出来 |
| 铺垫（Set-Up） | 1–10% | 建立世界、人物、赌注 |
| 催化剂（Catalyst） | ~10% | 改变一切的事件 |
| 争论（Debate） | 10–20% | 主角在"是否上路"之间挣扎 |
| 进入第二幕（Break into Two） | ~20% | 主角做出选择 |
| B 故事（B Story） | ~22% | 副线启动（常是爱情或主题线） |
| 玩乐与游戏（Fun and Games） | 20–50% | 兑现"卖点承诺"——读者买这本书就是为了看这些 |
| 中点（Midpoint） | ~50% | 假胜利或假失败 |
| 坏人逼近（Bad Guys Close In） | 50–75% | 反对力量加剧 |
| 一切尽失（All Is Lost） | ~75% | 最低点，死亡的阴影 |
| 灵魂黑夜（Dark Night of the Soul） | 75–80% | 主角消化损失 |
| 进入第三幕（Break into Three） | ~80% | 解决方案出现（往往来自 B 故事） |
| 终局（Finale） | 80–99% | 主角行动，击败反对力量 |
| 终场画面（Final Image） | ~99% | 与开场画面形成对照，证明改变 |

**适合**：节奏紧、卖点鲜明的商业类型（爱情、惊悚、动作、爽文、青少年小说）。

---

## 四、起承转合（Kishotenketsu）

东亚传统四段结构。**不要求中心冲突**——靠"转折（Ten）"来制造张力与新视角。常用于日常生活、文学、童话、教育叙事。

| 节拍 | 幕 | 说明 |
| --- | --- | --- |
| 起（Ki / Introduction） | 第一幕 | 介绍人物与场景 |
| 承（Sho / Development） | 第二幕 | 延展故事，加深理解 |
| 转（Ten / Twist） | 第三幕 | 意想不到的元素，视角转换 |
| 合（Ketsu / Conclusion） | 第四幕 | 把"转"与前文调和，得出新的整体理解 |

**适合**：日常生活、轻文学、童话、教育读物、探索主题胜过探索冲突的故事。**不适合**：以生死悬念或动作戏为主线的强类型小说。

---

## 五、五幕结构（Five-Act · 莎士比亚）

古典戏剧结构。允许有多个小高潮，适合复杂群像、政治剧、长篇史诗。

| 节拍 | 幕 | 说明 |
| --- | --- | --- |
| 交代（Exposition） | 第一幕 | 设定、人物、初始冲突 |
| 上升情节（Rising Action） | 第二幕 | 复杂化加深，紧张感累积 |
| 高潮（Climax） | 第三幕 | 转折点，张力顶点 |
| 下落情节（Falling Action） | 第四幕 | 后果展开，势头转移 |
| 收场（Dénouement） | 第五幕 | 解决与新的平衡 |

**适合**：政治剧、宫廷戏、史诗、群像戏、多线索长篇。一个故事里**可以同时存在多个五幕结构**（每条支线各跑一遍）。

## 六、其它常见模型（速查）

| 模型 | 来源 | 一句话特点 |
| --- | --- | --- |
| 七点结构（Seven-Point Story Structure） | Dan Wells | 用 7 个"挂钩点"把三幕压缩成可勾连的清单 |
| 雪花法（Snowflake Method） | Randy Ingermanson | 从一句话核心 → 一段 → 一页 → 全书，逐层细化 |
| 故事圈（Story Circle / Dan Harmon） | Dan Harmon | 8 步循环，强调"需求→寻→得→归"的人性弧 |
| 起搏点结构（Beat Sheet / Romancing the Beat） | Gwen Hayes | 专为爱情线设计 |
| 自由写作（Pantsing） | 无 | 不预设结构，靠场景驱动；适合短篇或试验性写作 |

---

## 七、选择结构的决策表

| 故事特征 | 推荐结构 |
| --- | --- |
| 标准长篇、读者预期清晰、商业类型 | **三幕结构** |
| 主角有明确内在蜕变（成长、救赎、复仇→放下） | **英雄之旅** |
| 节奏紧、卖点鲜明、读者买账的是"过程爽感" | **救猫咪** |
| 日常生活 / 主题探索 / 不依赖冲突 | **起承转合** |
| 多视角、多线索、政治剧、史诗 | **五幕结构** |
| 爱情线为主 / 浪漫类型 | 七点结构 + 爱情节拍 |
| 短篇 / 试验性 / 不预设大纲 | 自由写作（写后回填结构） |

---

## 八、混搭与裁剪

- **三幕为主，掺英雄之旅**：绝大多数奇幻长篇的实际做法。三幕给出框架，英雄之旅的"导师/试炼/复活"作为骨架里的节点。
- **五幕 + 三幕**：政治线用五幕（多个次高潮），整体故事用三幕。
- **救猫咪 + 起承转合**：爱情日常 + 一个反转时刻——常见于轻小说。
- **结构裁剪**：短篇或实验作品不必每条节拍都走一遍；可以只保留"激励事件—中点—高潮—收束"四个锚点，其余自由填充。

> 结构是脚手架，不是牢笼。写完初稿后，回头对照节拍清单，**缺节拍可以补**，**多余节拍可以删**——以故事效果为准。
