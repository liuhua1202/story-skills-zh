# 散文工艺守则（Writing Guidelines）

写章节正文时的散文工艺指南。具体语域、口吻、节奏密度以 `story.md` 中登记的 `genre` / `tone` / `pov` / `tense` 为准——这里给出的是**通用底线**，写奇幻、悬疑、言情、硬科幻都需要遵守的最小公约数。

> 与 `better-writing` 技能的关系：本目录内的守则是 Agent 在没有 `better-writing` 时也能用的兜底。如果当前环境已加载 `better-writing`，请把它的反套路检查、语域校准作为最终质检放在前面，再用本守则兜底。

---

## 一、Show, Don't Tell（用动作代替陈述）

情绪、性格、判断要让读者从动作、对话、感官细节里读出来，**不要直接命名情绪**。

| 反例（Tell） | 正例（Show） |
| --- | --- |
| "她很害怕。" | "她往后退了半步，指尖勾住门槛，眼睛却没离开那把刀。" |
| "他很生气。" | "他把茶盏往桌上一顿，瓷片磕进木头缝里，没说话。" |
| "这座城很繁荣。" | "码头上堆着来不及卸的盐袋；脚夫把扁担搁在船舷上歇气，笑声隔着三道巷子都听得见。" |

写完一段，问自己：**我刚才是不是直接告诉读者一个形容词？** 如果是，把这个形容词删掉，用一两个动作或感官细节替换。

---

## 二、POV 一致性

| POV 模式 | 视角口径 | 允许看到的范围 |
| --- | --- | --- |
| 第一人称（`我`） | 全篇过滤在叙述者一人的口吻、知识、偏见里 | 叙述者能感知、能想到、能推测的范围 |
| 第三人称有限（最常见） | 锁定一个角色，所有描写走他的感知 | 该角色能看见、能推断、能误判的范围 |
| 第三人称全知 | 可揭示任意角色内心，但**叙述者腔调要保持单一** | 全知视角，但要避免"每换一段就换一个声音" |

**禁止在一场戏里切换 POV**。需要切视角时另起一场戏（章节内用 `---` 分隔）或另开章节。判定口径：

- 切换 = 跳到另一个角色的内心独白 / 另一个角色才能知道的细节
- 没切换 = 同一个 POV 角色从外部观察另一个角色的表情、动作

---

## 三、对话

对话是性格放大器和剧情推进器，不是填字游戏。

- **每个角色的台词必须能从他自己的档案里找到支撑**——参 `characters/<id>.md` 里的"声音与口癖"小节。
- **对话标签克制**：能用"说"就别用"厉声宣告""喟叹着说"。标签越花哨，越打断节奏。
- **长台词要被动作打断**：一个人连讲五段不带任何动作描写，读者会出戏。每 2–3 句插一个动作或感知。
- **避免伪对话式信息倾倒**：不要让两个角色用对话把读者不需要知道的设定念出来——该用叙述或档案的就别塞进对话。
- **方言、术语、绰号**：首次出现时用上下文或叙述者轻轻带一句含义；不要靠脚注。

**反面教材**：A 问"我们该怎么办？"，B 答"我们要去北口，原因是……"（把整个设定念给读者听）。

**正面教材**：A 问"怎么办？"，B 沉默很久，掏出一枚令牌放在桌上；A 看见令牌，背脊慢慢挺直。

## 四、节奏

句子长度和段落长度是免费的鼓点。

| 想要的效果 | 节奏手法 |
| --- | --- |
| 紧张、动作、追逐 | 短句、断句、单句段，少用从句和插入语 |
| 沉思、回忆、抒情 | 长句、复合句、段落可以延展到半页 |
| 突然的静默或转折 | 短段、空行、单字句，独立成段 |
| 平缓的过渡 | 中长句混合，2–4 句一段 |

- **段落长度不要均质**。三段短、一段中、一段长，比五段同长度读起来更像呼吸。
- **场景长度匹配重要性**。一场决定命运的会面，写 3000 字不嫌多；一段交代性的出门，可以只写 200 字。
- **避免"中段瘫软"**。如果一章 4000 字中间突然出现连续两页的内心独白，要么砍掉，要么挪到下一章开头/结尾。

## 五、场景结构（Scene-Sequel 简版）

每一场戏至少要回答下面三个问题：

| 元素 | 问题 | 缺它的后果 |
| --- | --- | --- |
| **目标（Goal）** | POV 角色这一场戏想要什么？ | 读者不知道他/她在忙什么 |
| **冲突（Conflict）** | 谁/什么在挡路？ | 场景变成自说自话，没有张力 |
| **结果（Outcome）** | 这一场戏结束时的状态是什么？ | 场景读起来像停在半路 |

> 不是每场戏都需要爆炸式的冲突。安静的角色戏照样可以推动——但它必须**改变一点什么**（哪怕只是"两人之间多了一层没说出口的隔膜"）。

可选的第二拍 **反应（Reaction）**：POV 角色消化结果，常常是下一场戏的开头。

## 六、感官细节

不要让场景活在"视觉单一模"里。原则：

- **每场戏选 2–3 个感官**（视、听、嗅、触、味），不要五感全上。
- **感官细节要贴着地点档案走**。同一座城在雨季和旱季闻起来不一样；同一间屋子白天和晚上声音不一样。详见 `worldbuilding/locations/<id>.md`。
- **感官细节要贴着 POV 角色的心理状态**。心烦意乱的人走进花园，注意到的不是花香，而是割草机漏油的味道。
- **避免陈词滥调的感官**：汗味、铁锈味、血腥味堆叠。挑一个最具体的细节放大，其它点到为止。

---

## 七、章节开头

读者翻页（或滑动到下一章）只有几秒钟给你：

| 钩子类型 | 用法 | 适合场景 |
| --- | --- | --- |
| **动作钩子** | 直接抛出一个正在发生的事件 | 章节承接上一章结尾 |
| **声音钩子** | 用一句台词或一句旁白开篇 | 章节需要切换情绪 |
| **意象钩子** | 用一个具体物件或场景切入 | 章节打算铺垫气氛 |
| **问题钩子** | 用一个未解的悬念或反常细节切入 | 章节是悬念/解谜类 |

**避免**：

- 用天气开篇（除非你有意识地反套路）
- "醒来/起身/准备出门"三连（除非章节的关键就在于打破这种惯性）
- 上一章结尾的情绪**完全**延续到本章第一段——读者会觉得没翻页

---

## 八、章节结尾

结尾是下一章的入口，必须让读者愿意继续。

| 结尾类型 | 用途 |
| --- | --- |
| **动作断点** | 在一个动作的最高点戛然而止，适合动作/悬疑章节 |
| **揭示断点** | 抛出一个新信息或反转，适合解谜/政治章节 |
| **情绪断点** | 留一个安静的、未说出口的情绪，适合人物章节 |
| **提问断点** | 把一个核心问题用台词或旁白抛出来，适合主题章节 |

**最后一行**通常承担"让人想翻下一章"的责任。反复打磨最后一句——它和第一句同样重要。

---

## 九、连续性（写作前先做一次自检）

动笔前对照下面五项：

1. **上一章结尾**：情绪、动作、信息、断点——不要和本章开头打架。
2. **角色状态**：受伤、装备、情感、关系、已知信息——别让上章断了腿的人这章就跑步。
3. **时间线**：钟点、日期、季节、出行时长——别让"三天后到达"实际只过了一天。
4. **地点与道具**：地点是否登记在 `worldbuilding/locations/`？关键物品是否在 `continuity/state.md`？
5. **弧线进度**：本章应推进哪几条弧线的哪些节拍？是否要埋/兑现伏笔？

写完后做一次反向检查：

- 本章埋下的伏笔、抛出的问题、造成的状态变化，是否都登记到 `continuity/promises/` / `continuity/questions/` / 场景的 `state-changes`？
- 本章出现的所有角色、地点、道具，是否都登记在项目里？id 是否用 kebab-case？

## 十、常见雷区速查

| 雷区 | 替代做法 |
| --- | --- |
| 连续几段都是内心独白，没有外部动作 | 插入一个外部动作或感知，让内心独白"被中断一次" |
| 形容词堆叠（"美丽、优雅、动人"） | 选一个最具体的细节，其余删掉 |
| "突然""忽然""猛地"一连出现 | 改写句式结构，让速度感来自句子本身 |
| 解释性叙述过多（"他之所以这么做，是因为……"） | 把动机藏进动作或对话，必要时靠场景结果反推 |
| 章末总结性旁白（"从这天起，一切都不同了"） | 用一个具体细节收尾，让读者自己感受到变化 |
| POV 角色无理由地知道别人的内心 | 切到那人自己的场景，或让 POV 角色从外部行为推断 |
| 时间跳跃没交代（"三个月后"凭空出现） | 用一句话或一个物件标记时间过渡 |

## 十一、节奏与字数的健康区间

仅作参考；以 `story.md` 的设定和实际节奏为准。

| 章节类型 | 字数（中文字符）参考 |
| --- | --- |
| 短过渡章 | 1500–2500 |
| 标准剧情章 | 3000–5000 |
| 重大节拍章 | 5000–8000 |
| 高潮章 | 6000–10000 |

> 超过 10000 字的章节往往可以拆章；如果拆不开，先内部用 `---` 分场，再回填场景 frontmatter。
