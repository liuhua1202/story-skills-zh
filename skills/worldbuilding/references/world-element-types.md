# 世界体系类型参考（World Element Types Reference）

新建 `worldbuilding/systems/<id>.md` 时，先在 `frontmatter.type` 字段里登记体系类型，然后按下面对应的"核心提示清单"逐项回答——这是写好一个体系档案的最小问题集。

> 每个提示清单**不是大纲**，而是检验"是否覆盖完整"的检查表。回答不必长，但**每个问题都要被回答一次**（哪怕答案是"本体系不涉及"）。

---

## 一、魔法体系（Magic）

回答以下问题，覆盖一个魔法体系的全部主要面：

- **源头**：力量来自哪里——天生血脉 / 后天学习 / 神祇赐予 / 自然法则 / 器物传导 / 契约与代价
- **谁能用**：所有人 / 极少数 / 特定血统 / 经过训练的从业者 / 与特定器物绑定的人
- **代价**：每次使用付出什么——体力、寿命、记忆、理智、情感、关系、材料、随机事件
- **硬限制**：绝对做不到的事——复活死者、凭空造物、改变过去、跨越距离、预知未来等
- **社会认知**：被尊崇 / 被惧怕 / 被监管 / 被当作工具 / 被视为禁忌 / 与日常生活浑然一体
- **学派 / 分类**：内部是否有流派或分支？彼此如何区分（颜色、符箓、路径、概念）？
- **实践者组织**：是否形成行会、学院、宗派、隐秘团体？
- **与技术的交互**：是否与科技并存？互相排斥？互相强化？
- **学习曲线**：新手 / 熟手 / 大师各能做什么？

> 反模式警告：如果读者发现主角可以用这套魔法解决**任何**问题，那一定是漏写了几条硬限制——回头补。

---

## 二、政治体系（Political）

- **权力结构**：君主制 / 共和 / 寡头 / 神权 / 部族 / 公司联合 / 多方制衡
- **权力交接**：世袭 / 选举 / 武力夺取 / 任命 / 神意 / 推举 / 禅让
- **核心派系**：哪些势力集团存在？各自想要什么？
- **关键法律**：哪几条法律对本故事最重要（言论、税收、兵役、婚姻、贸易）
- **地区关系**：中央 vs 地方 / 国与国 / 城邦联盟 / 朝贡体系
- **当前冲突**：哪些矛盾已经在烧？
- **合法性来源**：被统治的人为什么服从——习惯、利益、恐惧、信念
- **决策流程**：日常事务与重大危机分别如何拍板

> 体系档案 vs 势力档案：`political` 是**制度**（议会、税法、继承法），`government` 是**组织**（议会下设的某个机构）。两者写不同文件。

---

## 三、技术体系（Technology）

- **整体技术层级**：石器 / 青铜 / 中世纪 / 火药 / 工业 / 信息 / 后稀缺
- **异常技术**：哪类技术异常超前或缺失？为何？别人知不知道？
- **与其它体系的交互**：与魔法、宗教、经济、政治的耦合点
- **关键技术控制者**：哪些势力 / 国家 / 公司把持着关键技术？
- **社会影响**：哪些日常决策被技术改变（交通、通讯、战争、医疗）
- **未解之谜**：哪些技术来自不可解释的源头（远古遗物、外星残骸、神祇遗迹）

> 写技术体系的核心是"边界"——它能做什么、做不到什么。如果读者无法判断某件事"用技术能不能解决"，那就是边界没写清楚。

---

## 四、宗教体系（Religion）

- **神祇与灵性力量**：哪些神 / 灵 / 概念存在？是被相信还是客观存在？
- **教阶与组织**：教廷 / 教区 / 修道会 / 苦行僧团 / 民间信仰
- **与政治权力的关系**：政教合一 / 王权高于神权 / 神权高于王权 / 互不干涉
- **仪式与节庆**：哪些仪式 / 节庆 / 日常礼拜在故事里被提及？
- **核心教义**：用一段话能讲清的最简版教义
- **宗教冲突**：教派分裂、异端、世俗化、神迹争议
- **与魔法体系的关系**：宗教与魔法是否同源？宗教是否禁止某些魔法？
- **俗信**：普通人相信什么、不信什么（常常和教义不一样）

---

## 五、经济体系（Economic）

- **货币与流通**：用什么做钱？跨地区通用吗？通胀情况如何？
- **核心产业**：什么在赚钱？矿、农业、手工、贸易、金融、信息？
- **关键资源**：本世界最重要的几样东西——粮食、铁、盐、能源、稀土、纸、橡胶……
- **财富分配**：贫富差距多大？流动性如何？
- **经济张力**：哪些矛盾正在引发冲突（贫富、城乡、行业、地域）
- **税收与再分配**：税怎么收？收上去用在哪？
- **与其它体系的关系**：经济与政治 / 军事 / 宗教如何互相影响

---

## 六、军事体系（Military）

- **武装力量组织**：中央军 / 地方军 / 雇佣兵 / 民兵 / 私兵 / 行会武装
- **主要武器与战术**：冷兵器 / 火器 / 机械 / 魔法 / 混合
- **战略传统**：哪类战术是主流（阵地战 / 游击战 / 海军 / 骑射 / 攻城）
- **军事与政治的关系**：军政合一 / 文官统军 / 军阀割据 / 兵权分离
- **现役冲突**：哪些战争正在进行 / 即将开打
- **兵役与社会**：当兵是义务 / 雇佣 / 赎买 / 阶层专属？军人退役后的社会地位
- **军费来源**：税收 / 战利品 / 捐赠 / 商业 / 殖民地掠夺

---

## 七、社会体系（Social）

- **阶级 / 等级**：世袭阶级 / 财富阶级 / 职业阶级 / 族群阶级 / 性别阶级
- **社会流动**：底层能否翻身？通过什么渠道？
- **性别角色**：男女各自被期待扮演什么？有没有第三条路？
- **家庭结构**：核心家庭 / 大家族 / 母系 / 父系 / 收继 / 公社
- **文化价值观**：集体主义 / 个人主义 / 荣誉观 / 孝道 / 宗教虔诚 / 商业精明
- **社会张力**：哪些矛盾正在撕裂社会（代际、城乡、阶层、性别、族群）
- **禁忌与污名**：什么事不能做、不能提、不能被发现
- **公共仪式**：婚丧嫁娶、节庆、人生转折点的社会化仪式

---

## 八、教育体系（Education）

- **知识传承途径**：学徒 / 学校 / 学院 / 口传 / 自学 / 神秘传承
- **谁有受教育权**：所有人 / 精英 / 特定行会 / 特定性别 / 特定阶层
- **机构类型**：国立 / 教会 / 行会 / 私塾 / 军队 / 地下
- **与社会阶层的交叉**：教育是阶层固化的工具还是打破阶层的通道？
- **被禁止的知识**：什么是禁书 / 禁学 / 禁术？
- **教材与考据**：本世界有没有"经典"？谁定的？
- **教育者群体**：教师的社会地位、待遇、组织

---

## 九、其它（Other）

如果你的体系不属于上面八类（例如法律、语言、媒体、医疗、性别、生态、地下世界、间谍网络、神话编年……），按以下通用清单回答：

- 它在世界中扮演什么角色
- 谁可以参与 / 谁被排除
- 它有什么硬规则（边界）
- 它与哪些其它体系耦合最深
- 当前的主要张力或变化

---

## 十、写体系档案时的通用检查清单

把上面的问题清单回答完之后，再问自己下面五个问题，确保体系**经得起故事的折腾**：

| 检查项 | 通过的标志 |
| --- | --- |
| **可以解决任何问题？** | 答"否"——任何主角都需要面对这个体系的硬墙 |
| **可以无代价使用？** | 答"否"——每次使用都付出可识别的代价 |
| **可以被反派滥用？** | 答"是"——反派用同一套体系也能作恶 |
| **存在二阶影响？** | 答"是"——它会影响日常、文化、政治 |
| **能与其它体系互相作用？** | 答"是"——它不是孤岛 |

如果五项里有任意一项不通过，回到对应问题补写。
